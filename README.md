# LifeLine Lab — Online Blood Test Booking and Lab Management System

A responsive frontend student-project demo built with HTML, CSS, and JavaScript.

## Features
- Searchable list of eight common blood tests and demo prices
- Appointment booking form
- Browser-local booking history and cancellation
- Lab dashboard with search, status filtering, and status updates
- Responsive mobile layout

## Run locally
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Deploy on GitHub Pages
1. Sign in to GitHub and create a new public repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the published URL shown in the Pages section.

## Important limitations
This is a frontend-only demo. Bookings are saved in the current browser's `localStorage`; they are not shared across devices or between users. The dashboard has no authentication. Do not use real patient information or real medical records. For production use, build a secure backend with authentication, access controls, data validation, privacy safeguards, and appropriate compliance review. Demo prices and test descriptions are illustrative; confirm real prices and preparation instructions with a licensed lab or clinician.
